# OpenClaw 2026.6.2~6.6 版本变更说明

发布时间：2026-06-27
适配教程版本：v1.10.0

---

## 📋 版本更新概要

v2026.6.2~v2026.6.6 是一个重要的安全强化版本，**100%向下兼容v2026.6.1所有配置**，无破坏性变更。本版本重点强化了安全边界、Exec审批机制、SSRF防护等安全特性，是OpenClaw走向生产级安全的关键版本。

---

## ✨ 新功能介绍

### 1. Exec审批机制强化

✅ 全新的Exec审批系统，提供更细粒度的命令执行控制：

| 特性 | 说明 |
|------|------|
| 失败关闭行为 | 审批超时或异常时默认拒绝执行 |
| 所有者身份验证 | 要求验证执行者身份，防止未授权执行 |
| 移动端推送审批 | 支持通过移动端推送进行审批确认 |
| 审批策略持久化 | 审批策略可持久化存储，避免重复配置 |

**配置示例**：
```json
{
  "exec": {
    "approval": {
      "enabled": true,
      "timeout": 30000,
      "failClosed": true,
      "ownerVerification": true,
      "mobilePush": true
    }
  }
}
```

**使用场景**：
- 生产环境命令执行审批
- 敏感操作二次确认
- 团队协作时的权限控制

### 2. SSRF防护增强

✅ 全面增强服务端请求伪造（SSRF）防护：

| 防护层 | 说明 |
|--------|------|
| 浏览器操作目标重检查 | 浏览器自动化操作前重新验证目标URL |
| 工作区环境文件限制 | 限制工作区环境文件的访问范围 |
| 内部网络访问控制 | 防止访问内部网络地址 |
| URL白名单机制 | 只允许访问预定义的URL白名单 |

**配置示例**：
```json
{
  "security": {
    "ssrf": {
      "enabled": true,
      "allowlist": [
        "https://api.openai.com",
        "https://api.anthropic.com"
      ],
      "blockInternal": true,
      "browserRecheck": true
    }
  }
}
```

### 3. Auth边界强化

✅ 认证和授权边界全面强化：

| 特性 | 说明 |
|------|------|
| OAuth迁移修复 | 修复OAuth认证状态迁移问题 |
| Provider凭证作用域 | 限制Provider API密钥的访问范围 |
| 认证状态持久化 | 认证状态可跨重启保持 |
| 多Provider隔离 | 不同Provider的认证状态相互隔离 |

**配置示例**：
```json
{
  "auth": {
    "providerScoping": true,
    "persistState": true,
    "migrationFix": true
  }
}
```

### 4. 运行时上下文保护

✅ 增强运行时上下文的安全性：

| 特性 | 说明 |
|------|------|
| 上下文泄露防护 | 防止敏感上下文信息泄露 |
| Token处理优化 | 更安全的Token处理和存储 |
| 文件系统边界 | 严格的文件系统访问边界控制 |
| 会话隔离 | 不同会话之间的上下文隔离 |

### 5. `/compact`命令增强

✅ 新增 `/compact` 命令，优化会话历史管理：

| 功能 | 说明 |
|------|------|
| 历史压缩 | 自动压缩冗余的会话历史 |
| 上下文优化 | 保留关键上下文，移除冗余信息 |
| Token节省 | 减少Token消耗，降低成本 |

**使用示例**：
```bash
# 压缩当前会话历史
/compact

# 压缩并保留最近N条消息
/compact --keep 10
```

## 🚀 升级步骤

### 常规升级

```bash
# 1. 停止gateway服务
openclaw gateway stop

# 2. 升级OpenClaw
openclaw update

# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix

# 4. 启动gateway服务
openclaw gateway start

# 5. 验证版本
openclaw version  # 输出应为v2026.6.6
```

### Docker部署升级

```bash
# 1. 拉取最新镜像
docker pull openclaw/openclaw:latest

# 2. 停止当前容器
docker stop openclaw

# 3. 启动新容器
docker run -d \
  --name openclaw \
  -v ~/.openclaw:/root/.openclaw \
  -p 18789:18789 \
  openclaw/openclaw:latest

# 4. 验证版本
docker exec openclaw openclaw version
```

## ⚠️ 注意事项

1. **Exec审批**：启用Exec审批后，所有命令执行都需要审批确认，可能影响自动化流程
2. **SSRF防护**：白名单机制可能导致某些合法URL被误拦截，需要仔细配置
3. **认证迁移**：升级后首次启动可能需要重新认证，请准备好认证凭据
4. **配置备份**：升级前建议备份`~/.openclaw/`目录
