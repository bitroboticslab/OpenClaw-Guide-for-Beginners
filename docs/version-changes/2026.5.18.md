# OpenClaw 2026.5.13~5.18 版本变更说明
发布时间：2026-05-25
适配教程版本：v1.8.0
---
## 📋 版本更新概要
v2026.5.13~v2026.5.18 是一个重要的功能增强版本，**100%向下兼容v2026.5.12所有配置**，无破坏性变更。本版本引入了 Plugin SDK、增强的 Skills 管理、新增 /stop 和 /btw 命令等实用功能。
---
## ✨ 新功能介绍
### 1. Plugin SDK（插件开发工具包）
✅ 全新的插件开发系统，支持自定义工具插件：
| 命令 | 功能说明 |
|------|---------|
| `defineToolPlugin` | 定义自定义工具插件 |
| `openclaw plugins build` | 构建插件 |
| `openclaw plugins validate` | 验证插件配置 |
| `openclaw plugins init` | 初始化插件项目 |

**使用示例**：
```bash
# 初始化新插件
openclaw plugins init my-plugin

# 构建插件
openclaw plugins build my-plugin

# 验证插件
openclaw plugins validate my-plugin
```

### 2. Skills 管理增强
✅ 技能管理命令全面升级：
| 命令 | 功能说明 |
|------|---------|
| `openclaw skills install --global` | 全局安装技能 |
| `openclaw skills update --global` | 全局更新技能 |
| `openclaw skills search` | 搜索技能 |
| `openclaw skills list --versions` | 查看技能版本 |

**使用示例**：
```bash
# 全局安装技能
openclaw skills install weather --global

# 更新所有技能
openclaw skills update --global

# 搜索技能
openclaw skills search productivity
```

### 3. 新增交互命令
✅ 新增两个实用的交互命令：

#### /stop 命令
用于停止当前正在运行的 Agent 任务：
```
你: /stop
AI: 已停止当前任务。
```

#### /btw 命令
用于在任务运行时插入旁白问题：
```
你: /btw 这个任务还需要多久完成？
AI: 预计还需要 2 分钟完成。
```

### 4. QA 测试工具
✅ 新增质量保证测试命令：
| 命令 | 功能说明 |
|------|---------|
| `openclaw qa suite` | 运行测试套件 |
| `openclaw qa suite --runtime-parity-tier` | 运行运行时一致性测试 |
| `openclaw qa coverage --tools` | 查看工具覆盖率 |

### 5. Obsidian 集成
✅ 新增 Obsidian 笔记集成：
- 支持直接读取 Obsidian vault 中的笔记
- 支持通过 CLI 操作 Obsidian
- 适用于知识管理和文档工作流

## 🚀 升级步骤
### 常规升级
```bash
# 1. 停止gateway服务
openclaw gateway stop
# 2. 升级OpenClaw
openclaw update
# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix
# 4. 启动gateway服务
openclaw gateway start
# 5. 验证版本
openclaw version # 输出应为v2026.5.18
```
### Docker部署升级
```bash
# 拉取最新镜像
docker pull openclaw/clawdock:latest
# 重启容器
docker restart openclaw
```
