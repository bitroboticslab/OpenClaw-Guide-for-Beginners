# OpenClaw 2026.5.8~5.12 版本变更说明
发布时间：2026-05-25
适配教程版本：v1.8.0
---
## 📋 版本更新概要
v2026.5.8~v2026.5.12 属于稳定性优化版本，**100%向下兼容v2026.5.7所有配置**，无破坏性变更。主要聚焦于心跳机制、语音可靠性和认证持久化的改进。
---
## ✨ 新功能介绍
### 1. 心跳机制优化
✅ 改进了定时任务的心跳机制：
- 心跳运行现在遵循群组/频道的 `message_tool` 可见回复策略
- 支持模型特定的 Codex 运行时配置
- 失败的内部工具输出保持私密，不会泄露到群组
### 2. 语音可靠性提升
✅ 语音会话稳定性改进：
- 修复语音会话在断线后的恢复机制
- 改进语音识别的准确性
- 优化语音延迟，提升实时对话体验
### 3. 认证持久化
✅ OAuth 认证状态现在可以正确持久化：
- 避免每次重启后需要重新登录
- 支持多设备间的认证状态同步
- 提升 Codex 和其他 OAuth 依赖功能的稳定性

## 🔗 兼容性说明
✅ **完全向下兼容**：所有v2026.5.7版本的配置无需任何修改即可直接升级到v2026.5.12，无功能失效风险。
---
## 🚀 升级步骤
### 常规升级
```bash
# 1. 停止gateway服务
openclaw gateway stop
# 2. 升级OpenClaw
openclaw update
# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix
# 4. 启动gateway服务
openclaw gateway start
# 5. 验证版本
openclaw version # 输出应为v2026.5.12
```
### Docker部署升级
```bash
# 拉取最新镜像
docker pull openclaw/clawdock:latest
# 重启容器
docker restart openclaw
```
