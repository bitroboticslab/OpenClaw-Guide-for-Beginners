# OpenClaw 2026.6.10 版本变更说明

发布时间：2026-06-28
适配教程版本：v2.2.0

---

## 📋 版本更新概要

v2026.6.10 是一个重要的功能增强版本，**100%向下兼容v2026.6.9所有配置**，无破坏性变更。本版本重点引入了 Fast Talks 自动模式、Provider 路由改进、跨通道会话身份识别等核心特性。

---

## ✨ 新功能介绍

### 1. Fast Talks 自动模式

✅ Fast Talks 新增自动模式，根据消息复杂度自动选择快速/标准回复路径：

| 特性 | 说明 |
|------|------|
| 自动模式 | 简单问题走快速路径，复杂问题走标准路径 |
| 复杂度判断 | 基于消息长度、关键词、上下文自动判断 |
| 延迟优化 | 简单问题响应延迟降低 40%+ |
| 可配置阈值 | 支持自定义复杂度阈值 |

**配置示例**：
```json
{
  "fastTalks": {
    "enabled": true,
    "mode": "auto",
    "autoThreshold": 0.6,
    "fastModel": "gpt-4o-mini",
    "standardModel": "gpt-4o"
  }
}
```

**使用效果**：
- 简单问候和常见问题自动走快速模型
- 复杂分析和代码任务自动走标准模型
- 无需手动切换，智能路由

### 2. Provider 路由改进

✅ 多个 Provider 路由优化和容错改进：

| Provider | 改进内容 |
|----------|----------|
| 智谱/GLM | 过载时自动降级到备用模型 |
| Ollama | `/think` 命令支持深度推理模式 |
| Z.AI | 推理链路优化，支持流式推理输出 |

**配置示例**：
```json
{
  "providers": {
    "zhipu": {
      "fallbackModel": "glm-4-flash",
      "overloadDetection": true
    },
    "ollama": {
      "thinkMode": true,
      "thinkDepth": 3
    },
    "zai": {
      "reasoning": {
        "streaming": true,
        "chainOfThought": true
      }
    }
  }
}
```

### 3. 跨通道会话身份识别

✅ 用户在不同通道的对话现在可以共享会话身份：

| 特性 | 说明 |
|------|------|
| 统一身份 | 同一用户在 Telegram、飞书等通道共享身份 |
| 上下文延续 | 跨通道切换时保持对话上下文 |
| 隐私控制 | 用户可选择是否启用跨通道身份 |
| 安全隔离 | 不同通道的数据仍然隔离存储 |

**配置示例**：
```json
{
  "identity": {
    "crossChannel": true,
    "identityMapping": {
      "enabled": true,
      "autoLink": false,
      "requireConfirmation": true
    }
  }
}
```

### 4. Prompt 上下文边界

✅ 新增 Prompt 上下文边界控制，避免上下文溢出：

| 特性 | 说明 |
|------|------|
| 上下文窗口 | 可配置的上下文窗口大小 |
| 自动截断 | 超出窗口时自动截断旧消息 |
| 重要消息保留 | 关键系统消息不被截断 |
| 摘要压缩 | 支持对截断内容生成摘要 |

**配置示例**：
```json
{
  "context": {
    "maxTokens": 128000,
    "truncationStrategy": "smart",
    "preserveSystemMessages": true,
    "summarizeTruncated": true
  }
}
```

### 5. 可信工具策略强制执行

✅ 工具调用安全策略全面增强：

| 特性 | 说明 |
|------|------|
| 工具白名单 | 只有白名单中的工具可被调用 |
| 权限分级 | 工具按危险等级分级管理 |
| 审计日志 | 所有工具调用记录审计日志 |
| 用户确认 | 高危工具调用需用户确认 |

**配置示例**：
```json
{
  "tools": {
    "trustedPolicy": {
      "enabled": true,
      "whitelist": ["web-search", "calculator", "code-runner"],
      "dangerousTools": ["file-delete", "shell-exec"],
      "requireConfirmation": ["file-delete", "shell-exec"],
      "auditLog": true
    }
  }
}
```

### 6. Session Transcript SDK

✅ 新增会话转录 SDK，支持导出和分析对话记录：

| 特性 | 说明 |
|------|------|
| 多格式导出 | 支持 JSON、Markdown、HTML 格式 |
| 过滤查询 | 按时间、用户、通道过滤 |
| 统计分析 | 对话统计和分析功能 |
| API 访问 | 通过 REST API 访问转录数据 |

**使用示例**：
```bash
# 导出会话记录
openclaw sessions export --format markdown --output ./transcripts

# 查看会话统计
openclaw sessions stats --last 7d

# 通过 API 访问
curl http://localhost:18789/api/sessions/transcripts
```

### 7. Docker/Podman 超时优化

✅ 容器部署场景下的超时处理优化：

| 特性 | 说明 |
|------|------|
| 启动超时 | 容器启动超时自动重试 |
| 健康检查 | 定期健康检查自动恢复 |
| 优雅关闭 | 支持优雅关闭和资源清理 |
| Podman 兼容 | 完整的 Podman 支持 |

**配置示例**：
```json
{
  "docker": {
    "startupTimeout": 60000,
    "healthCheck": {
      "enabled": true,
      "interval": 30000,
      "retries": 3
    },
    "gracefulShutdown": true,
    "shutdownTimeout": 30000
  }
}
```

### 8. StepFun Provider 恢复

✅ StepFun Provider 完整恢复，支持全系列模型：

| 模型 | 说明 |
|------|------|
| step-1-8k | 8K 上下文标准模型 |
| step-1-32k | 32K 上下文长文本模型 |
| step-1-128k | 128K 上下文超长文本模型 |
| step-2-16k | 16K 上下文增强模型 |

**配置示例**：
```json
{
  "providers": {
    "stepfun": {
      "apiKey": "YOUR_STEPFUN_API_KEY",
      "defaultModel": "step-1-32k",
      "models": ["step-1-8k", "step-1-32k", "step-1-128k", "step-2-16k"]
    }
  }
}
```

## 🚀 升级步骤

### 常规升级

```bash
# 1. 停止gateway服务
openclaw gateway stop

# 2. 升级OpenClaw
openclaw update

# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix

# 4. 启动gateway服务
openclaw gateway start

# 5. 验证版本
openclaw version  # 输出应为v2026.6.10
```

### Docker部署升级

```bash
# 1. 拉取最新镜像
docker pull openclaw/openclaw:latest

# 2. 停止当前容器
docker stop openclaw

# 3. 启动新容器
docker run -d \
  --name openclaw \
  -v ~/.openclaw:/root/.openclaw \
  -p 18789:18789 \
  openclaw/openclaw:latest

# 4. 验证版本
docker exec openclaw openclaw version
```

## ⚠️ 注意事项

1. **Fast Talks 自动模式**：首次启用后需要积累一定对话数据才能准确判断复杂度
2. **跨通道身份**：需要用户主动确认身份关联，不会自动关联
3. **可信工具策略**：启用后可能影响部分第三方插件的正常使用
4. **Session Transcript SDK**：导出大量数据时可能影响性能
