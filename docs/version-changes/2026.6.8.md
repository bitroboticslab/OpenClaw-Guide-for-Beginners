# OpenClaw 2026.6.7~6.8 版本变更说明

发布时间：2026-06-27
适配教程版本：v2.0.0

---

## 📋 版本更新概要

v2026.6.7~v2026.6.8 是一个重要的功能增强版本，**100%向下兼容v2026.6.6所有配置**，无破坏性变更。本版本新增了GLM-5.2和Claude Haiku 4.5模型支持，增强了Telegram富文本渲染，引入了用量页脚功能，是OpenClaw通道能力大幅提升的关键版本。

---

## ✨ 新功能介绍

### 1. 新模型支持

✅ 新增两款重要模型支持：

| 模型 | 提供商 | 特性 | 推荐场景 |
|------|--------|------|----------|
| **GLM-5.2** | 智谱AI | 强大的中文理解能力 | 中文对话、文档处理 |
| **Claude Haiku 4.5** | Anthropic | 快速响应、低成本 | 日常对话、快速任务 |

**配置示例**：
```json
{
  "providers": {
    "zhipu": {
      "apiKey": "YOUR_API_KEY",
      "models": ["GLM-5.2"]
    },
    "anthropic": {
      "apiKey": "YOUR_API_KEY",
      "models": ["claude-haiku-4.5"]
    }
  }
}
```

### 2. Telegram富文本渲染

✅ Telegram通道支持结构化文本渲染：

| 格式 | 说明 | 示例 |
|------|------|------|
| **表格** | Markdown表格自动渲染 | `| 列1 | 列2 |` |
| **列表** | 有序/无序列表 | `- 项目1` |
| **引用块** | 代码引用块 | `> 引用内容` |
| **代码块** | 语法高亮代码块 | ` ```python ... ``` ` |

**配置说明**：
```json
{
  "channels": {
    "telegram": {
      "richText": true,
      "markdownMode": "full"
    }
  }
}
```

**使用效果**：
- 发送Markdown格式消息时，Telegram会自动渲染为富文本
- 支持表格、列表、代码块等复杂格式
- 提升消息可读性和用户体验

### 3. 用量页脚功能

✅ 新增原生用量页脚渲染器：

| 功能 | 说明 |
|------|------|
| `/usage`命令 | 查看当前用量统计 |
| 自动页脚 | 消息底部自动显示用量信息 |
| 模板配置 | 可自定义页脚模板 |
| 格式控制 | 支持固定小数位格式化 |

**使用示例**：
```bash
# 查看当前用量
/usage

# 查看详细用量
/usage --detailed
```

**页脚配置**：
```json
{
  "usage": {
    "footer": {
      "enabled": true,
      "template": "Tokens: {tokens} | Cost: ${cost}",
      "decimalPlaces": 2
    }
  }
}
```

### 4. Provider路由优化

✅ 模型路由和Provider处理全面增强：

| 特性 | 说明 |
|------|------|
| OpenRouter规范化 | Provider前缀标准化处理 |
| Google Vertex规范化 | Vertex API调用优化 |
| SecretRef认证 | 管理Secret引用认证 |
| OAuth image路由 | Codex OAuth图像默认路由 |
| 模型浏览发现 | 有界模型发现机制 |

**配置示例**：
```json
{
  "providers": {
    "openrouter": {
      "apiKey": "YOUR_API_KEY",
      "prefix": "openrouter/"
    },
    "google": {
      "apiKey": "YOUR_API_KEY",
      "vertex": true
    }
  }
}
```

### 5. `/btw`旁白命令增强

✅ `/btw`命令功能增强：

| 功能 | 说明 |
|------|------|
| 插入旁白 | 在对话中插入旁白问题 |
| 上下文保持 | 不中断当前任务流程 |
| 多轮对话 | 支持多轮旁白对话 |

**使用示例**：
```bash
# 在任务执行中插入旁白
/btw 顺便问一下，这个配置需要重启吗？

# 在长对话中插入问题
/btw 你能解释一下这个错误吗？
```

### 6. `/model`模型切换增强

✅ 模型切换功能增强：

| 功能 | 说明 |
|------|------|
| 快速切换 | 快速切换当前模型 |
| 模型列表 | 显示可用模型列表 |
| 切换确认 | 切换后确认提示 |

**使用示例**：
```bash
# 切换到指定模型
/model GLM-5.2

# 查看可用模型
/model --list

# 切换回默认模型
/model --default
```

## 🚀 升级步骤

### 常规升级

```bash
# 1. 停止gateway服务
openclaw gateway stop

# 2. 升级OpenClaw
openclaw update

# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix

# 4. 启动gateway服务
openclaw gateway start

# 5. 验证版本
openclaw version  # 输出应为v2026.6.8
```

### Docker部署升级

```bash
# 1. 拉取最新镜像
docker pull openclaw/openclaw:latest

# 2. 停止当前容器
docker stop openclaw

# 3. 启动新容器
docker run -d \
  --name openclaw \
  -v ~/.openclaw:/root/.openclaw \
  -p 18789:18789 \
  openclaw/openclaw:latest

# 4. 验证版本
docker exec openclaw openclaw version
```

## ⚠️ 注意事项

1. **Telegram富文本**：需要Telegram Bot支持MarkdownV2格式
2. **新模型**：GLM-5.2和Claude Haiku 4.5需要单独的API密钥
3. **用量页脚**：默认关闭，需要手动启用
4. **Provider路由**：多Provider配置时注意前缀规范化
