## 📋 版本更新概要

v2026.5.19~v2026.6.1 是一个重要的稳定性增强版本，**100%向下兼容v2026.5.18所有配置**，无破坏性变更。本版本引入了完整的Skill Workshop、SQLite支持的队列系统、以及多项通道稳定性改进。

## ✨ 新功能介绍

### 1. Skill Workshop（技能工作坊）

✅ 全新的一站式技能管理界面，支持：

| 功能 | 说明 |
|------|------|
| 技能浏览 | 可视化浏览所有可用技能 |
| 技能安装 | 一键安装/卸载技能 |
| 技能配置 | 图形化配置技能参数 |
| 技能更新 | 自动检测并更新已安装技能 |
| 技能开发 | 内置技能开发和测试工具 |

**使用示例**：
```bash
# 打开Skill Workshop
openclaw skills workshop

# 或通过Web界面访问
# http://localhost:18789/skills
```

### 2. SQLite-backed Queues（SQLite队列系统）

✅ 使用SQLite作为队列后端，提升可靠性：

| 特性 | 说明 |
|------|------|
| 持久化存储 | 队列数据持久化，重启不丢失 |
| 事务支持 | 原子操作，保证数据一致性 |
| 并发安全 | 多进程/线程安全访问 |
| 自动清理 | 过期队列自动清理 |

**配置说明**：
```json
{
  "queue": {
    "backend": "sqlite",
    "path": "~/.openclaw/queue.db",
    "cleanup_interval": 3600
  }
}
```

### 3. MiniMax M3模型支持

✅ 新增MiniMax M3模型支持：

| 模型 | 特性 | 推荐场景 |
|------|------|----------|
| MiniMax-M3 | 原生多模态能力 | 图文理解、创意写作 |

**配置示例**：
```json
{
  "providers": {
    "minimax": {
      "apiKey": "YOUR_API_KEY",
      "models": ["MiniMax-M3"]
    }
  }
}
```

### 4. 外部化插件支持

✅ 插件架构升级，支持外部化插件：

**安装方式**：

openclaw plugins install @openclaw/copilot

## 🚀 升级步骤

### 常规升级

```bash
# 1. 停止gateway服务
openclaw gateway stop

# 2. 升级OpenClaw
openclaw update

# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix

# 4. 启动gateway服务
openclaw gateway start

# 5. 验证版本
openclaw version  # 输出应为v2026.6.1
```

### Docker部署升级

```bash
# 1. 拉取最新镜像
docker pull openclaw/openclaw:latest

# 2. 停止当前容器
docker stop openclaw

# 3. 启动新容器
docker run -d \
  --name openclaw \
  -v ~/.openclaw:/root/.openclaw \
  -p 18789:18789 \
  openclaw/openclaw:latest

# 4. 验证版本
docker exec openclaw openclaw version
```

### 云服务器升级

```bash
# 1. SSH登录服务器
ssh user@your-server-ip

# 2. 进入OpenClaw目录
cd /path/to/openclaw

# 3. 执行升级
openclaw gateway stop
openclaw update
openclaw gateway start

# 4. 验证版本
openclaw version
```

## 📝 新增配置项

### SQLite队列配置

```json
{
  "queue": {
    "backend": "sqlite",
    "path": "~/.openclaw/queue.db",
    "cleanup_interval": 3600,
    "max_size": 10000
  }
}
```

### Skill Workshop配置

```json
{
  "skills": {
    "workshop": {
      "enabled": true,
      "port": 18789,
      "auto_update": true
    }
  }
}
```

### 外部化插件配置

```json
{
  "plugins": {
    "external": true,
    "registry": "https://registry.openclaw.ai",
    "auto_install": false
  }
}
```

## ⚠️ 注意事项

1. **SQLite依赖**：v2026.6.1默认使用SQLite作为队列后端，确保系统已安装SQLite3
2. **插件迁移**：外部化插件需要重新安装，使用`openclaw plugins install`命令
3. **配置备份**：升级前建议备份`~/.openclaw/`目录
4. **Web界面**：Skill Workshop需要Web界面访问，确保端口18789可访问
