# OpenClaw 2026.6.9 版本变更说明

发布时间：2026-06-27
适配教程版本：v2.1.0

---

## 📋 版本更新概要

v2026.6.9 是一个重要的稳定性增强版本，**100%向下兼容v2026.6.8所有配置**，无破坏性变更。本版本重点增强了Telegram富文本投递、Codex原生插件支持，以及exec功能增强（本版本标题特性）。

> **📌 前瞻性内容说明**：本教程v2.1.0版本中收录的「通道恢复机制」和「独立Provider插件架构」文档为前瞻性内容，对应功能在 v2026.6.10~v2026.6.11 中正式稳定，提前收录以便用户了解演进方向。

## ✨ 新功能介绍

### 1. Telegram富文本投递增强

✅ Telegram通道投递能力全面升级：

| 特性 | 说明 |
|------|------|
| 富HTML发送 | 支持发送富HTML格式消息 |
| Markdown保留 | 保留原始Markdown格式 |
| 贴纸路径 | 支持贴纸路径渲染 |
| 进度渲染 | 长任务进度实时渲染 |

**配置示例**：
```json
{
  "channels": {
    "telegram": {
      "richText": true,
      "htmlDelivery": true,
      "markdownPreserve": true,
      "progressRender": true
    }
  }
}
```

**使用效果**：
- 消息格式更丰富，支持HTML标签
- 长任务执行时显示进度条
- 贴纸和媒体文件路径正确渲染

### 2. Codex原生插件支持

✅ Codex模式下的原生插件支持：

| 功能 | 说明 |
|------|------|
| 原生插件 | Codex线程内原生插件执行 |
| 插件管理 | `/codex plugins`命令管理 |
| 插件启用/禁用 | 支持单个插件启用/禁用 |
| 插件列表 | 查看已安装的Codex插件 |

**使用示例**：
```bash
# 查看Codex插件列表
/codex plugins

# 启用指定插件
/codex plugins enable google-calendar

# 禁用指定插件
/codex plugins disable google-calendar
```

**配置示例**：
```json
{
  "plugins": {
    "entries": {
      "codex": {
        "config": {
          "codexPlugins": {
            "enabled": true,
            "plugins": ["google-calendar", "github"]
          }
        }
      }
    }
  }
}
```

### 3. 通道恢复机制增强

✅ 通道连接恢复机制全面增强：

| 特性 | 说明 |
|------|------|
| 自动重连 | 断线后自动重连 |
| 状态保持 | 恢复后保持会话状态 |
| 消息补发 | 断线期间消息补发 |
| 多通道支持 | 所有通道统一恢复机制 |

**故障排查**：
```bash
# 查看通道状态
openclaw channels status

# 手动触发通道恢复
openclaw channels recover

# 查看通道日志
openclaw channels logs --follow
```

### 4. 独立Provider插件架构

✅ Provider插件外部化，支持独立管理：

| 特性 | 说明 |
|------|------|
| 外部化插件 | Provider作为独立插件 |
| 热插拔 | 支持运行时加载/卸载 |
| 版本管理 | 独立版本控制 |
| 配置隔离 | 每个Provider独立配置 |

**安装示例**：
```bash
# 安装Provider插件
openclaw plugins install @openclaw/provider-openai

# 安装Provider插件
openclaw plugins install @openclaw/provider-anthropic

# 查看已安装的Provider
openclaw plugins list --type provider
```

**配置示例**：
```json
{
  "providers": {
    "openai": {
      "plugin": "@openclaw/provider-openai",
      "apiKey": "YOUR_API_KEY"
    },
    "anthropic": {
      "plugin": "@openclaw/provider-anthropic",
      "apiKey": "YOUR_API_KEY"
    }
  }
}
```

### 5. exec功能增强

✅ exec命令执行功能增强：

| 特性 | 说明 |
|------|------|
| 安全执行 | 更安全的命令执行环境 |
| 超时控制 | 可配置的执行超时 |
| 输出捕获 | 完整的输出捕获 |
| 错误处理 | 更好的错误处理机制 |

**配置示例**：
```json
{
  "exec": {
    "timeout": 30000,
    "maxOutput": 10000,
    "safeMode": true
  }
}
```

## 🚀 升级步骤

### 常规升级

```bash
# 1. 停止gateway服务
openclaw gateway stop

# 2. 升级OpenClaw
openclaw update

# 3. 自动修复配置（可选，推荐执行）
openclaw doctor --fix

# 4. 启动gateway服务
openclaw gateway start

# 5. 验证版本
openclaw version  # 输出应为v2026.6.9
```

### Docker部署升级

```bash
# 1. 拉取最新镜像
docker pull openclaw/openclaw:latest

# 2. 停止当前容器
docker stop openclaw

# 3. 启动新容器
docker run -d \
  --name openclaw \
  -v ~/.openclaw:/root/.openclaw \
  -p 18789:18789 \
  openclaw/openclaw:latest

# 4. 验证版本
docker exec openclaw openclaw version
```

## ⚠️ 注意事项

1. **Telegram富文本**：需要Bot支持HTML格式，部分旧版客户端可能不兼容
2. **Codex插件**：需要Codex模式启用，普通模式不可用
3. **独立Provider**：需要重新安装Provider插件，旧配置自动迁移
4. **通道恢复**：首次升级后可能需要手动触发一次通道恢复
